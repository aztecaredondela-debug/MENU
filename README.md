# Táper de la semana

Menú rotativo de 4 semanas, recetas y lista de la compra. Los cambios se guardan en `data/menu.json` de este repositorio, así los ven todos.

## Puesta en marcha
1. Crea un repositorio **público** en GitHub y sube estos archivos (Pages en repos privados requiere plan de pago).
2. Settings, Pages: Deploy from a branch, `main`, carpeta `/ (root)`.
3. Settings, Collaborators: invita a tu mujer.
4. Cada uno crea un token en github.com/settings/personal-access-tokens/new: solo este repositorio, permiso **Contents: Read and write**.
5. Abre la web, pulsa «Conectar» y pega el token. No lo subas nunca al repositorio.
